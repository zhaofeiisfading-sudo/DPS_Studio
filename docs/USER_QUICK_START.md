# PDV Studio 快速上手指南（Windows v0.2.1）

> 几分钟完成安装、波形分析并得到 Origin 直接画图的 5 个标准结果文件。

---

## 1. 安装（1 分钟）

1. 双击运行 `PDV-Studio-Setup-x64.exe`（无需管理员权限）。
   - 若弹出 **Windows 已保护你的电脑**，点击 **更多信息 → 仍要运行**。
2. 安装路径保持默认非系统盘目录（如 `D:\Programs\PDV Studio`；单盘自动为 `%LOCALAPPDATA%\Programs\PDV Studio`）。
   - **不要选 `C:\Program Files`** 等受保护只读目录。
3. 可按需勾选以下两项（默认均未勾选）：
   - `Create a desktop shortcut`（创建桌面快捷方式）
   - `Add command-line tool (pdv) to current user PATH`（把 `pdv` 加入当前用户环境变量）
4. 点击 **Install** 完成安装。

> **提示 · 命令行与桌面一键拖放**
> - **CLI 已随软件安装，无需额外单独安装**（`pdv.exe` 与桌面程序同在安装目录）。安装时只需决定是否勾选 PATH；**若终端无法直接输入 `pdv`，请按说明补加 PATH**（详见 [README_for_agent.md](README_for_agent.md)）。
> - 安装目录 `launchers\` 下与发布压缩包内还附带两个 **`.bat` 一键分析脚本**（`1550 nm / 0° / LiF` 与 `无窗口`）。复制到桌面后，直接把 `.csv` 或 `.dat` 文件拖到脚本图标上即可全自动出图，免开软件和终端。

---

## 2. 首次打开与桌面 4 步分析

- 从桌面快捷方式或开始菜单打开 **PDV Studio**（默认简体中文，可在 `设置 → 语言` 切换 English）。
- 界面上方 4 步即完整流程：

```text
1 数据与时频  →  2 脊线提取  →  3 速度结果  →  4 复核与导出
```

1. **导入数据**：把 `.csv` / `.dat` / `.txt`（逗号、Tab 或空格分隔）拖进软件欢迎窗口，核对时间列（0 起算）、信号列（最多 3 路）与单位（`s/ms/us/ns`、`V/mV`）后点击 **导入**。
2. **时频与脊线**：点击右侧 **计算时频图**（或顶部 **快速分析**）；在 `2 脊线提取` 核对时间窗和搜索频带后点击 **确认区域并继续分析**（弱信号或强干扰可切换 **人工范围** 手绘上下边界）。
3. **光学修正**：进入 `3 速度结果`，在右侧核对真实实验条件：`真空波长`（默认 `1550 nm`）、`窗口材料`（`LiF` 或 `无窗口修正`）与 `观测角度`（默认 `0°`）。需要时间归零可在 `事件参考…` 选择自动候选或手动输入。

---

## 3. 导出结果（5 个标准文件，CLI 与桌面端完全统一）

进入 `4 复核与导出`（多通道默认勾选 **`全部通道（合并导出）`**，也可单选某一路），选择 `时间零点` 后点击 **选择导出目录… → 导出结果** → **打开目录**：

| 输出文件 | 用途说明 |
|---|---|
| `velocity_raw.csv` | 全时间网格原始工作速度（未做质量门控与平滑） |
| `velocity_gated.csv` | 仅保留通过质量门控帧；未通过帧为空白单元格 `""`（不写 `"nan"`），可直接进 Origin 画断线散点/折线 |
| `velocity_display.csv` | **推荐直接导入 Origin 绘图**：仅基于通过帧做端点保留 3 帧平滑、短缺口（`<=5` 帧）线性桥接及可追溯起跳前零平台 |
| `run_summary.json` | 实验条件、通过率、自动下限重试记录、显示平滑/桥接溯源与告警汇总 |
| `spectrogram_ridge.png` | 时频图 + 灰虚线工作脊线 + 红实线正式门控脊线（多通道自动纵向堆叠） |

> 仅在明确需要求导时，才勾选 `加速度 CSV · 原始差分`（CLI 加 `--acceleration`）额外生成 `acceleration.csv`；默认已不再导出冗余的 `*_detail.csv`。

---

## 4. 常见注意事项

- **实验条件务必核对**：激光波长、观测角度和窗口材料决定修正系数，软件不会代猜。
- **安全与更新**：顶部 **帮助 → 检查更新…** 可从 GitHub 正式版下载安装包并校验 SHA-256（升级前请保存结果并关闭主窗口与 `pdv.exe`）；**帮助 → 意见反馈…** 仅在你勾选后附带基础版本/系统信息，绝不收集数据或路径。
- **原位保留配置**：设置、自定义材料和缓存集中在 `<安装目录>\userdata\`，同目录覆盖升级不会丢失。

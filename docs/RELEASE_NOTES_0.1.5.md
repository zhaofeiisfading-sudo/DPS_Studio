# PDV Studio 0.1.5 — Windows 本地便携包

发布日期：2026-11-02。沿用本地 0.1.0–0.1.4 发布序列；远端版本未核验。

- 速度页增加加速度切换，基于当前主图速度与 STFT 时间坐标求导。内部和 CSV 使用 m/s²，图轴以 10⁹ m/s² 显示。
- 复核导出页可额外输出加速度 CSV，附带速度来源、质量标记、窗口修正参数和方法说明；原有速度导出方式保留。
- 修改窗口参数后可中文命名、保存、另存和重新选择本地配置。内置 LiF 配置与自定义系数明确区分。
- 事件参考三个选项改为纵向排列，避免窄侧栏截断文字。

加速度是重建速度的数值导数，可能放大噪声及速度跳变。已知无效点、缺口、插值点及纯显示平台保持 NaN，不跨越这些点求导；有限结果不代表高置信度。未增加平滑、删点、插值或峰值限幅，也未改动现有 LiF 公式。自定义系数不代表其材料适用性已验证。

解压整个 ZIP，双击 `PDV Studio.exe`；保留 `_internal` 同级目录，无需安装 Python/Conda。此包未进行代码签名。源码提交及构建时间见同目录 `BUILD_INFO.json`。本次只生成本地发布包，不发布 GitHub Release。

# 逐阶段与逐通道评价

## 起跳、平台、下降及弱信号

- **起跳。** 在 14 段冻结起跳内，A、B + S、S2 分别有 55、63、65 个过 S 中心（共同分母 69）。`20201210m` 的首个有效 GHz 候选由 B 在冻结起点后约 6.0 ns 给出，C 同频同中心。`20201211m` 的 B + S 与 S2 首个支持比 A 提前 6.4 ns，两者都跟随可见约 4.8 GHz 线。`ch3` 多出的点紧贴冻结边界，详见下文。`20201214m` 多出的是约 0.184 GHz 的长窗候选。其后出现的约 6.3 GHz 主脊超出频带。其余通道的 S2 未增加起跳支持中心。
- **平台。** B + S 与 S2 在 2,227 个共同支持中心均有输出，未出现 >100 MHz 换支。A 跟对单一平台时更平稳。例如 `20221017a` 平台在三法同支持的相邻对上，A/B + S/S2 的频差绝对值中位数为 1.40/5.25/5.25 MHz，A 与 B 的同中心频差中位数约 −0.11 MHz。`20260607_ch1` 平台对应 0.55/1.08/1.08 MHz。这些是输出抖动，窗长差异和原信号变化均有贡献。
- **下降、回升。** C 仅在两路各补一帧下降，均没有 >100 MHz 的同帧换支。`20201211m` 的 835.2 ns 处，C 的 1.007 GHz 靠近 B 的 0.983 GHz 未过 S 候选，仍可见间断。`20201214m` 增补约 5.99 GHz，位于主脊进入频带附近。两路 `20260630-1` 的回升曲线重合良好（约 0.30–0.35 GHz）。居中窗跨过转折时可提前显现或平滑瞬态，不能从这些曲线辨认真实因果延迟。
- **弱信号。** S2 相对 B + S 只增加 `ch3` 的 3.822 GHz 一帧。B 已提出约 3.820 GHz，C 借 Dechirp 的原生调频率使局部拟合过 S。另有 4 帧的原 B 支持频率被替换（`ch3` 两帧，`20260630-1` 每路一帧）。谱脊偏弱、相互靠近或有短时竞争时，单一赢家不足以确认物理支路。
- **静止、噪声和未定。** 在冻结静止区，B 的 3,020 个候选中有 2,983 个被 S 剔除，B + S 与 S2 仍分别留下 37 和 47 个中心。冻结噪声区还包含具有原电压支持的窄带成分，B + S 与 S2 分别留下 1,427 和 1,437 个中心。49 个新 S 中心中，静止、噪声各 10，未定 24。它们应连同谱形和实验背景回查，不能直接记为运动恢复或假阳性。

## 三个重点通道

### 20201210m_ch1

原始谱显示前驱的低频/直流泄漏，以及约 3.7 GHz 平台和下降。A 的峰选择被约 0.059 GHz 占据，全部 297 个共同中心均无 S。B + S 和 S2 的 218 个共同中心输出逐点相同。起跳段的 60.8/64.0 ns 分别为 3.714/3.723 GHz，S2 直接选 B 候选，只有 STFT 家族提供支持。平台中两条都走约 3.70–3.83 GHz，下降到约 2.39 GHz 后出现更低的间断支路。后者身份未定。S2 连线在相邻中心之间可能呈现近垂直的支路切换。 [全程同谱](../../../artifacts/TASK-020/figures/20201210m_ch1/full_1.png) · [起跳去噪对照](../../../artifacts/TASK-020/figures/20201210m_ch1/s02_3.png)

### 20260630-1_ch2

原始谱能看到约 0.55 GHz 主脊和多条近倍频成分。A/B + S/S2 均跟随平台、约 0.55→0.30 GHz 的下降和随后的回升。B + S 与 S2 均有 8 个起跳支持点，首点同为 2,262.4 ns。S2 的三个前置候选 0.244/0.163/0.227 GHz 出现在 2,230.4–2,243.2 ns 的冻结背景段，各仅一票家族，物理含义未确认。

在 3,254.4 ns，B + S 由较低支路跳到约 0.507 GHz，S2 改选约 0.362 GHz，次帧 B + S 与 S2 又保留约 0.51 GHz 候选。图 3 可见相邻低频竞争点。S2 的该点正弦/调频拟合 R² 为 0.075/0.531，支持一次局部调频解释，尚不足以确定这一段应走哪条线。S2 保留了噪声段中可见的约 0.5 GHz 窄脊，该窄脊的物理来源仍待确认。 [回升叠加](../../../artifacts/TASK-020/figures/20260630-1_ch2/s05_2.png) · [弱信号四面板](../../../artifacts/TASK-020/figures/20260630-1_ch2/s06_3.png) · [共识图](../../../artifacts/TASK-020/figures/20260630-1_ch2/consensus.png)

### ch3_ch1

起跳冻结线约为 1,066.25 ns。前一帧（1,065.6 ns，q=42624）B + S 和 S2 都接受 3.216 GHz，B 原门控拒绝。冻结段内第一帧（1,068.8 ns，q=42752），A/B 原生输出约 3.674/3.659 GHz，均未过 S。S2 选 3.414 GHz，沿原谱展宽的起跳区连接到后续 3.659 GHz。Dechirp 的正弦/调频拟合 R² 为 0.151/0.452。S2 填了冻结起跳首帧空缺，使段内首个 S 点前移一帧。把冻结线前紧邻的点也计入时，B + S 与 S2 最早已支持帧相同。

弱段 1,132.8 ns 的 3.822 GHz 补点与 B 原始候选几乎同频，两者原始谱线一致，差别在 S 可使用的局部调频模型。弱段另有两次 >100 MHz 改选，三法共同支持的相邻对中，频差绝对值中位数为 A 11.1、B + S 30.1、S2 36.8 MHz。随后快速下降和换支区域的 1,225.6/1,232.0/1,235.2 ns，B + S 约为 3.238/2.884/1.404 GHz，S2 改为 3.093/2.733/1.560 GHz。图中可见快速变化及相邻候选，S2 仍有 GHz 级跳变。两段都适合保留竞争候选供复核。噪声区 q=72704 的 3.760 GHz 簇曾有四家族同票、S1=1，仍被 S2 拒绝。 [起跳图](../../../artifacts/TASK-020/figures/ch3_ch1/s01_1.png) · [弱段曲线](../../../artifacts/TASK-020/figures/ch3_ch1/s02_2.png) · [快速变化区候选](../../../artifacts/TASK-020/figures/ch3_ch1/s03_3.png)

## 同等筛选改变了什么

B + S 与 S2 同时支持的 5,351 帧中，5,324 帧同频（差小于 0.01 Hz），14 帧改变但未超过 100 MHz，13 帧改变超过 100 MHz。49 个额外支持中心中，9 个来自已有的 STFT 候选并集，40 个需要异构候选；其中 16 个额外中心的 S2 赢家要靠原生调频率过 R² 门。5,186 个相邻共同支持对上的 37→32 次大跳变，变化分布在起跳、弱信号和未定段。各自完整发布序列的 B + S/S2 跳变为 37/35，A/B 原生门控的计数为 0/21。这四列的相邻有效对不同，A 在强直流和换支附近经常没有输出。

S2 的投票不要求至少两家族，实际有 281 个赢家仅获一个家族的 S 支持。S1→S2 的同源簇数 27,775→5,779，后者还有 359 个中心含竞争支持簇。稀疏画法压低全图背景，S 门把无支持簇清空，跨家族投票在残余簇中重排选择。存在干净却身份未定的晚期谱线，也存在多个家族同时受杂散影响的情况。 [筛选前后共识图](../../../artifacts/TASK-020/figures/ch3_ch1/consensus.png) · [全部新增和换支明细](../../../artifacts/TASK-020/data/paired_changes.csv) · [逐阶段诊断](../../../artifacts/TASK-020/data/stage_diagnostics.csv)

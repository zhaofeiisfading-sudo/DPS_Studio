# TASK-020｜真实 PDV 三方法直接对照

[打开 14 路交互图册](../../../artifacts/TASK-020/gallery.html) · [逐通道与失败案例](COMPARISON.md) · [参数和复现](VALIDATION.md)

**正式频率曲线优先用去均值 512 点 STFT 加原波形证据筛选（B + S）。S2 适合回查快速起跳、断点和竞争支路。** 这批原始电压包含可支持的杂散和其它反射，最终目标支路仍需实验背景或独立观测确认。实验波长、角度和窗口条件未经确认，主结果为拍频 GHz。

1. **S2 与传统 Balanced STFT（A）。** S2 明显改善强直流记录的 GHz 谱脊跟踪。例如 `20201210m_ch1` 上 A 的最强候选压在约 0.059 GHz，S2 沿可见的约 3.7 GHz 谱脊进入平台和下降。强单脊记录里 A 已可给出稳定曲线。A 原生门控更严，按原生发布曲线计的大跳变少于 S2。
2. **S2 与去均值短窗 STFT（B）。** S2 的发布点更少落在原电压证据不足处。B 已恢复 `20201210m_ch1` 的起跳、平台和下降，也跟随多数通道的弱信号和回升。部分 B 的原生拒绝点仍可由电压支持，直接比较两条发布曲线会混入门控差异。
3. **S2 与 B + S。** 相同 S 规则下，两者都发布零个未过 S 的点。在共同支持的 5,186 个相邻对上，>250 MHz 跳变从 37 减到 32。S2 新增 49 个支持中心，其中 44 个在静止、噪声或未定段。最清楚的运动案例是 `ch3_ch1` 起跳段首帧的补点及一个弱段补点。两者在冻结起跳线前一帧已有同一个支持点。另有 13 个已支持 B 频率被替换超过 100 MHz，部分位于多脊冲突。
4. **干净背景的来源。** 共识图只把局部候选簇的票分画到窄频带，其它格点置零。对同一批候选，S 从 27,775 个 S1 簇中去掉 21,996 个没有 S 成员的簇，其中 486 个原先有高共识。单独给 B 加 S 也筛掉 4,098 个原始候选。簇评分会影响所选支路，背景变暗主要由图的表示方式与 S 门控解释。
5. **正式提取按信号条件选择。** 强单脊平台可用 A 核对稳定性。直流显著或快速过渡用 B + S，保留空缺与质量状态。短时弱信号或多支路冲突再用 S2 提供备选，并对照原谱、相邻中心及原电压。频带截断（如约 6.3 GHz 平台）应先核对搜索范围；滤波或投票无法从固定 6 GHz 主比较带中恢复它。

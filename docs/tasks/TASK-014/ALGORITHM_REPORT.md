# TASK-014 阶段专项实验

## 低频平台上的单峰精修

TASK-008/009 提供冻结 STFT、Dechirp 与 13 文件索引，TASK-010 比较窗长和步长。TASK-011/012 的经典和人工分段工作区分开保留结果，TASK-013 把长窗收益与局部拟合收益拆开。此次只改变一个决策：低频平台上，将双候选频率剖面搜索缩减到排名第一的谱峰。其余阶段延用 TASK-013 简单映射，不增加 GUI 算法池条目。

固定 2048 点支撑、相同人工段边界和相同频带。在去除局部常数与线性趋势后的 Hann 谱上取候选，以其为中心在 ±Fs/L 内最小化剩余平方和。模型为 y = A cos(2πfτ) + B sin(2πfτ) + c + dτ/T，y、A、B、c、d 的单位为 V，τ 和支撑时长 T 为 s，f 为 Hz。每次试探 f 都重新求线性最小二乘。搜索限于 5 MHz～min(8 GHz, 0.49Fs)。沿用 TASK-013 的边界拒绝、最少周期、设计矩阵条件数及相对线性背景的 R² 门槛。支持不足输出 NaN。单峰与双峰均使用同一门控；匹配 FFT 使用同一支撑、趋势模型、频带及门控。原始 STFT768 有不同的搜索下限和质量规则，其与阶段映射之差不能单独归因于拟合。

## 验证设计

48 条新波形，40 GHz，长度 12,800 点。低频平台 16 条，包含 15、30、60、120 m/s。起跳、加速、减速、回升、弱信号杂波、交叉、消光与纯噪声各 4 条。生成器沿用冻结 TASK-013 分布，使用之前实验未使用的实例索引 32 起步，故独立性指随机实现而非新实验装置。带真值分段按原生成器抖动 ±2 ns，这是额外输入。评估用相同整数中心（H128），不对轨迹插值。合成表观速度按 λf/2、λ = 1550 nm 计算。研究门控、波形外推和软件正式速度修正分开。

低频 1360 个目标中心中，原始 STFT 支持 RMSE 为 5.866 m/s，覆盖 48.01%；匹配长窗 FFT 为 1.497 m/s、93.09%；双峰和单峰拟合均约 0.268 m/s、93.16%。在共同支持的 1266 个中心，FFT 和单峰仍为 1.497 和 0.268 m/s。以整条波形为抽样单位的配对 bootstrap（5000 次）得到 RMSE 差的 95% 百分位区间 [−1.593, −0.816] m/s。重叠帧未作独立重复。逐波形偏差、R² 中位数及最大条件数见 low_paired.csv；R² 衡量残差能量，不验证物理身份。单峰每条耗时 170.7 ms，双峰 400.9 ms，匹配 FFT 43.9 ms。

从匹配 FFT 到单峰，覆盖只多 1 个中心；显著的误差差异出现在已有支持的中心。由原始 STFT 到简单映射的变化同时包含静止标注、不同窗长、频带、去趋势及质量门控。纯噪声无目标，不能纳入目标 RMSE；synthetic.csv 的 absent_output_n 单列无目标输出。弱杂波/交叉下，统一使用单峰比双峰多 5 个错支路中心；起跳 MAE 只统计成功检测者。保留简单映射，不把该候选自动推广到弱信号、起跳或加减速。

## 全部可用真实输入

TASK-009 索引覆盖 13 个物理文件、17 路完整电压流。每通道只设置覆盖全记录的 unknown 段，直接比较三种估计，不凭外观赋予真实阶段标签。共 11305 个中心，STFT768、匹配 FFT、单峰拟合分别得到 5332、4950、5164 个有限值。与 STFT 共同有限的中心分别为 4338（FFT）和 4523（单峰）；其中差异超过 100 MHz 的为 23 和 31。逐流计数和耗时见 real.csv。真实数据仅作 Hz 级描述，无法判定哪一条是物理目标，不能给出真实 RMSE、起跳准确度或速度改善。

## 五套窗的用途

均用 Hann、NFFT=4096；表中时长以 40 GHz 为例。保留既有 preset ID，确保保存的数值型自定义预设可继续读入。

| 内置选择 | W/H | 支撑 / 采样间隔 (ns) | 使用条件 |
|---|---|---|---|
| 极高时间分辨（实验） | 256/128 | 6.4 / 3.2 | 很快且足够强的跳变；低频周期数少 |
| 高时间分辨 | 512/128 | 12.8 / 3.2 | 起跳与快速加减速 |
| 平衡 | 1024/64 | 25.6 / 1.6 | 通用起点，侧重稳定平台与覆盖 |
| 高频率分辨 | 1536/128 | 38.4 / 3.2 | 缓变且频率接近的结构 |
| 极高频率分辨（实验） | 2048/128 | 51.2 / 3.2 | 长稳定段、低频周期或近邻峰；最易混合瞬态 |

TASK-010 fresh、共同中心、supported motion 的 6512 个目标中，768/128 与 1024/64 的覆盖由 92.94% 到 94.61%，失败由 14.82% 到 13.18%，pooled RMSE 从 120.04 到 119.02 m/s，但每条波形等权的 macro RMSE 从 38.65 到 39.11 m/s。1536/128 的覆盖为 94.35%，失败 13.47%。采用 H64 是为降低相对 H32 的帧数与计算成本；共同中心无额外频率信息。1024/64 相邻窗共享 93.75% 样本，这不是估计误差相关系数。微分仍使用真实时间坐标和连通有效片段；拟合需显式选择物理时宽，密集帧不能作为独立样本推断置信度。

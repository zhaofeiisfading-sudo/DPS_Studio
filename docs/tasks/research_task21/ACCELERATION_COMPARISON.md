# research_task21｜加速度对照

速度差分保留 Production 既有语义：对最终显示速度（working 表观速度经角度与窗口处理）按实际时间差分，排除明确无效区和显示平台。可选 50 ns 局部线性模式仍在，保留旧端点、缺失及质量规则。质量不佳的有限 working 点可能参与导数；正式质量筛选后的速度另有独立列。本次实验对照设 0°、无窗口修正，使两种加速度均在表观域比较。采用 GUI 已配置的 1550 nm，未对这三份记录做独立光学标定。

Dechirp 在 STFT 帧中心取原始电压窗，拟合
`V(t) = C + A cos(2π f_c τ + π k τ²) + B sin(2π f_c τ + π k τ²)`，其中 `τ = t − t_c`，时间来自原始 SI 样点。Research 参考实现用调频率网格和局部 Fourier 投影，实际保存了斜率。Production 用类似投影初始化，再对实值电压作 Hann 加权最小二乘，解析消去 `A,B,C`，联合细化 `f_c,k`。STFT 的 working 频率只限定中心搜索至种子 ± 约两倍窗长倒数，斜率没有从速度序列取差分。可参照 [二阶局部多项式 Fourier 变换的 IF/CR 估计分析](https://doi.org/10.1016/j.sigpro.2022.108794) 理解窗口与频率、斜率方差的关系；该研究未验证本实现的判据。

结果由 `v_app = λ₀ f_c/2`、`a_app = λ₀ k/2` 换算。Hz/s × m 得 m/s²。正负表示**正频拍频支路**增减；实值单通道不能判定物体的运动方向。Dechirp **只输出表观量**，不把速度修正当作统一倍率。默认 512 点（40 GS/s 时约 12.8 ns），斜率请求上限 ±10¹⁷ Hz/s，最低加权 R² 为 0.50；过长窗另限制无量纲二次项以控制搜索规模。拟合结果有 R² 与逐帧状态；R² 是波形残差诊断，并非加速度误差条。

已知事件参考、检测候选及超过可拟合斜率加频率分辨裕量的相邻种子跳变切断窗口；边界处不截窗续算。无种子、弱拟合、优化失败、搜索/采样带边缘、可分辨的残差竞争分量与半窗不一致分别标记，数值留 NaN。未识别的小阶跃、近邻不可分辨的多音、非线性调频和振幅变化仍可使估计偏置。窗口重叠造成相邻结果相关，3.2 ns 帧间隔不是时间分辨率。

- **平台及噪声：**候选后 100–250 ns，前两份各有 47 个 Dechirp 点。差分的加速度 MAD 分别为 0.170 / 0.297，512 点 Dechirp 为 0.323 / 0.662，768 点为 0.222 / 0.433（单位 10⁹ m/s²）。短窗 256 点则为 0.504 / 1.047。长窗改善这一平稳段的重复性，差分在这两段仍更稳定。MAD 是结果散布，不能视为真值误差。
- **快速变化：**20260630-1 的时频图在候选附近有能量转移，512 与 768 点在 +28.8 ns 的估计为 22.28 与 16.28；256 点同一小区最大仅 4.78（+35.2 ns）。原始电压约 ±210 mV 处存在平顶，提示可能削顶；没有前端标定可确认原因。20260607 的 256 点在 +6.4 ns 给出 36.99，而 512 点在该时刻拒绝。首个通过窗和峰值随窗长变，不宜把差值当作仪器延迟或真实峰值。三份差分结果均出现失锁或支路切换附近的大尖峰，属于有歧义的峰。
- **弱信号：**20260701 的 −25 至 +60 ns 和 +100 至 +250 ns，三种 Dechirp 窗均无通过点；512 点在 +441.6 ns 才出现首个通过点。全程有 169 帧弱拟合、106 帧跨边界、15 帧无候选。较晚的 326 个通过点只是局部波形支持，不能证明物理支路身份。
- **时间和代价：**默认拟合单通道约 0.97、2.87、0.97 s；复用既有速度的差分约 0.66–0.75 ms。768 点约 1.8–5.9 s。三例 512 点的未通过共 1,540 帧，主要是弱拟合（1,147）和跨边界（278）；没有优化失败。拒绝点不以差分补齐。

解析波形以同一恒定种子恢复正、负和零斜率，另检查 SI 换算、绝对时间偏置、明确阶跃、无候选、低信噪比和竞争频率。真实记录没有独立加速度真值；Dechirp 的价值是独立的原始电压证据和可解释的缺测，代价是耗时、覆盖下降和窗口依赖。结果支持把它作为对照工具，默认仍用原始差分。

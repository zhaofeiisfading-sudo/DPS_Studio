## 一、核心问题回答

> **我们是否真正找到了比简单 STFT（`B1`：512 点去均值 Hann STFT）更有价值的 PDV 信号处理方法？优势出现在哪些真实数据、哪些物理阶段，又付出了什么代价？**

**回答：是——但突破并不来自单纯追求覆盖率、平滑度或再换一种瞬时频率估计器，而是来自“物理时间尺度对齐的相位相干积分 + 原电压分侧阶跃/削顶验证 + 窗内谱对比度与多分支物理语义解耦”（`M4_phase_coherent` + 无监督 `regime`）。**

在严格保持相同原始电压、同中心样本网格 `q`、统一 `[50 MHz, 6 GHz]` 主频带且零视觉标签泄漏的公平评测下（全部 **10 文件 / 14 通道 / 9,475 个主中心**）：

1. **真正稳定超越简单 STFT 的三类物理阶段与具体真实数据**：
   - **急减速末段与弱相位相干尾（`decline` / `weak_signal`）**：当调频率 $|\mathrm{d}f/\mathrm{d}t| \sim (5\text{–}35)\times 10^{15}\ \mathrm{Hz/s}$ 或信噪比低至宽带 `raw_chirp_r2_256ns ≈ 0.04–0.10` 时，固定样本窗 `6.4 ns`（`B1`/`B+S`）在 `80 GS/s` 下退化为更短的物理分辨时间，或在 `B+S` 的 256 点无斜率能量门控下大面积失效。`M4` 通过物理时间对齐的 `25.6–38.4 ns` 去势去调频（quadratic detrend + chirp-matched quadrature）把相同弱尾段的相干 SNR 推高 `+6.8`～`+8.9 dB`，且同时以窗内 35 分位 `CA-CFAR`（`≥ 11.5 dB`）与左右半窗一致性压制震后宽带噪底虚警：
     - `20201211m_ch1`（`decline` $n=36$）：`B1 = 18/36`、`B+S = 20/36` → **`M4 = 35/36`**，干净追踪 `0.836 → 0.748 GHz` 至 `108.3832 µs`；
     - `20221017a_ch1`（`weak_signal` $n=41$）：`B+S = 1/41`、`B1 = 30/41`（含跳变）→ **`M4 = 30/41`** 且零 `>4 GHz` 离群点和零噪声阶段误报（`0/85`）；
     - `ch3_ch1`（`weak_signal` $n=44$）：`B1 = 36/44` → **`M4 = 44/44`**（零跳变、`0/326` 静态误报；Phase 2B 引入 `CA-CFAR` 后彻底消除晚时噪底两条伪轨迹，`noise` 误报由 `29/213` 降至 **`3/213`**）。
     - `20231019-ch1_ch1`（留出集）：`decline = 137/137`、`unknown = 34/35`、相邻 `>250 MHz` 跳变 **`0`**，25.6 ns 原始波形解释度 `0.5346 → 0.7288`，分半相干度 `0.7447 → 0.8898`。
   - **起跳台阶边缘与脉冲前基线振荡抑制（`onset`）**：原电压分侧阶跃投影避免了窗内阶跃混叠：
     - `20201210m_ch1` 提前一个中心（`3.2 ns`）于 `138.7576 µs` 捕获 `~3.7 GHz` 起跳（`3/3` vs `B1 2/3`）；
     - 留出集 `20201214m_ch1` 的 `82.956–82.965 µs` 存在低频脉冲基线抖动，**`B1`（`2/5`）将 `~0.20 GHz` 基线振荡误判为速度**，而 `M4` 在 `6 GHz` 主频带下正确拒绝该假低频（`0/5`），并在独立 `8 GHz` 诊断中正确锁定约 `6.39 GHz` 真起跳（`3/5`）。
   - **多分支并存 / 晚时 CW 竞争 / 重度限幅削顶下的主支路保持（`weak` + 晚期 CW + `rail_clipped`）**：
     - `20260630-1_ch2` 在 `747.20–747.24 µs`（`0.23–0.29 GHz` 减速靶面波与 `~0.51 GHz` CW 并存）实现 **`12/12` 连续锁定主支路**（修复 `747.2052 µs` 单帧缺口并发布 `secondary_hz ≈ 0.515 GHz`），而 `B1`、`M1`、`M3` 均在此段跳上 CW 支路；
     - 在 **4 组自然双通道配对（`ch1` 高增益削顶 vs `ch2` 宽量程）** 的严苛检验中，Phase 3 曾暴露 `20260630-1_ch1`（`10.32%` 样本触轨）因削顶奇数次谐波 `3f ≈ 1.53–1.67 GHz` 触发 CW 拮抗惩罚，导致 `ch1` 停滞于 `0.6025 GHz` 旁瓣并跳至 `3f`（`17` 帧 `>250 MHz` 分歧）。在 `_select` 排除强基频的 2–8 阶谐波后，Phase 3B 将 `20260630-1` 的双通道 **`<=30 MHz` 一致率从 `80.91%` 提升至 `98.01%`**（`>250 MHz` 分歧 **`17 → 0`**，`<=100 MHz` 达 **`100.00%`**，削顶窗内中位频差从 `47.69 MHz` 降至 `1.87 MHz`），`20260630-2`（`ch1` 14.9% 削顶）达 `460/460` 联合发布（`99.13% <= 30 MHz`），`20260701` 达 `99.35% <= 30 MHz`（`ch2` 噪声段 **`0/96`** vs `B1 24/96`）。

2. **明确承认的局限、瓶颈与付出的代价**：
   - **计算成本**：全 14 通道共 **9,475** 主中心上，`M4` 冷启动总耗时 **`215.01 s`**（中位 `13.21 s/通道`，`200k` 样本的 `20260630-1` 达 `31.51 s`），显著高于 `B1` 的 **`18.99 s`**（**约 11.3 倍算力开销**）。因此 `B1` 仍是快速初筛/交互式预览基准，`M4` 适合用于离线精算与疑难弱信号/多分支分段重建。
   - **信号物理可辨识性极限（`20201211m`、`20201214m` 弱尾、`20231019` 末端）**：经过原始相位相干测量与 `38.4 ns` 匹配扫频确认，`20201211m_ch1` 在 `108.393 µs` 之后（冻结 `weak_signal` 后 ~24/28 帧）及 `20201214m_ch1` 在 `83.555 µs` 之后（`weak_signal` 只余 `2/19` 帧），信号相对本地噪底已降至不可辨识水平（`< 10–11 dB`）。这是**光学反射衰减与硬件采集噪底构成的物理信噪比极限**，并非参数或选择器保守所致。
   - **硬件模拟带宽与固定频带截断（`20201214m_ch1`）**：全部通道在 `~8.5 GHz` 出现模拟前端衰减；而主基准强制限定在 `[50 MHz, 6 GHz]` 时，`20201214m_ch1` 处于 **`~6.40 GHz` 的主平台（`114/114`）被协议硬截断为空白**。在严格分离的 `[50 MHz, 8 GHz]` 副诊断中，`M4_8G` 恢复 **`114/114`** 平台（中位 `6.399959 GHz`，与 `B1_8G 113/114` 差中位 `2.910 MHz`），证实此处瓶颈是 `[50 MHz, 6 GHz]` 搜索上限与采集系统带宽边界。
   - **静默态真实微弱低频/窄带扰动与晚时 CW 的物理归属争议**：`M4` 在冻结 `stationary` / `noise` 标签下发布 `1,610/5,179` 个点（高于 `B1` 的 `1,474`），但其中 **`1,387` 个点属于被双通道独立证实的晚时真实窄带 CW 峰**；剔除 CW 工况后其余 `223` 点主要集中在高增益 `20260630-1_ch1`（`96`）与 `ch2`（`45`）等通道的真实共模窄带振荡：例如 `20260630-1` 上 `746.16–746.20 µs` 的 `~100 MHz` 前驱波动在 `ch1`/`ch2` 呈同相锁定（$\cos\Delta\varphi = +0.998$），`744.09–744.17 µs` 的 `~1.83 GHz` 微弱条纹在两通道同时可见（`ch1 16.5 dB` vs `ch2 11.7 dB`）。在无独立干涉仪或电干扰隔离记录前，这类**低幅真波形究竟属光路微动前驱、激光器模式泄漏还是触发电磁串扰**，以及 `20260607` `555.70–555.75 µs` 双支路切换和全集晚时 CW 的光学物理归属，均**按规范保留物理争议**。

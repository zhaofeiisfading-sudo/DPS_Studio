# research_TASK19｜GUI 设计与桌面验收

旧版同时常驻左侧流程、底部诊断和右侧表单。新版把四步流程移到顶部，诊断从 **视图 → 诊断与数据** 打开；图形在默认布局占用更多宽高。右侧只显示当前步骤的参数，宽度可拖动。浅色工作面、深色步骤条、统一的焦点和主按钮用于区分导航、参数和计算。布局状态由 Qt 持久化，旧三栏拆分布局自动回退到新布局；语言和材料配置各自保留。

| 操作 | 新界面 |
|---|---|
| 导入 | 文件结构、列预览及通道映射在同一对话框；明确显示源时间、源电压单位。导入后显示点数、通道和采样率；源单位映射可悬停查看。 |
| 区间与 STFT | 直接拖动波形中的范围，或编辑起止值、重置。窗型、窗长、重叠、步长与 FFT 长度同处一栏。高级配置另开；计算完成即打开脊线页。 |
| 追踪与结果 | 保留自动和人工范围提取。图形支持缩放、平移、范围复位和坐标读数。事件参考折叠，校正角、波长、窗口材料与材料参数保留。 |
| 加速度 | 独立选择原始差分或局部线性拟合；纵轴显式显示 `10⁹ m/s²`，添加零线和可见时间段的纵轴适配。缺口与尖峰保留。 |
| 导出 | 右下角固定主操作；第一次导出可直接选目录。复核页固定速度预览，离开后恢复原显示量。导出成功反馈在状态栏，文件清单在日志。 |

冗余说明移到工具提示、诊断和 metadata；例如事件前显示平台、质量门、校正有效范围及加速度解释仍可查。仪器设置由用户确认，界面不会从文件名推断实验波长、角度或材料。

真实截图位于 `artifacts/research_TASK19/figures/`。验收脚本创建正常 Windows Qt 窗口，等待窗口进入 exposed 状态，通过 `QScreen.grabWindow` 抓取原生窗口。通过代码驱动真实控件和数据链；pytest 的离屏图没有作为桌面截图。

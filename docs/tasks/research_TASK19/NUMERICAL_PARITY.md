# research_TASK19｜真实记录数值对照

对照基线为 Production `677a22df0566f8403786a0b4d8eac11ff55bcf4f` 的冻结源码。旧版与新版使用同一 Python/NumPy/SciPy、相同原始文件、相同配置与完整数据范围。三份输入均使用 GUI 预览的逗号、UTF-8、无表头，明确选择第 0 列 s、第 1 和 2 列 V。导出验证以指定单通道为单位，未将两路电压或速度混合。

| 输入 / 导出通道 | 采样点 | STFT 帧 | 正式表观速度有限点 | 自定义校正后原始差分 / 拟合有限点 | 选择原因 |
|---|---:|---:|---:|---:|---|
| `20260607.csv` / ch1 | 80,000 | 620 | 390 | 558 / 544 | 含持续可追踪脊线段，同时有前段背景与弱信号 |
| `20260630-1.csv` / ch2 | 200,001 | 1,557 | 767 | 1,546 / 1,546 | 较长记录，578 帧峰值位于搜索边界，检验复杂质量状态 |
| `20260701.csv` / ch1 | 80,000 | 620 | 340 | 605 / 601 | 弱或失锁区较多：169 帧歧义峰、15 帧无可检出拍频 |

平衡配置保持 Hann、窗长 768、重叠 640、步长 128、FFT 长度 4096；每帧有 2,049 个单边频率坐标。代表采样率约 40 GS/s，帧间隔约 3.2 ns，窗宽约 19.2 ns，FFT 网格约 9.77 MHz。网格间隔不等于真实频率分辨能力。

对照链：导入 → 计算时频图 → 确认自动搜索区 → 检查正式和 working 速度 → 分别应用 15°/无窗口、15°/内置 LiF、15°/自定义窗口（仅把 b1 改为 0.82）→ 切换加速度 → 导出绝对时间。使用既有配置的 1550 nm 和测试角度/材料参数来复现软件行为。这些参数没有作为该批实验的独立标定结论。

- 逐数组比对 dtype、shape、有限点数和字节 SHA-256。STFT 时间、频率、复系数、正式表观与 working 速度、三种校正下的正式修正与显示速度、原始差分及 50 ns 局部拟合全部一致。NaN 的位置也随数组指纹一起一致。
- 加速度图的 x 与 STFT 时间换算一致，y 与共享的 SI 导数乘 `1e-9` 逐元素一致。原始差分在实际时间轴进行，沿用非均匀内部差分和分段端点规则，跳过明确无效区及仅显示平台；局部线性是显式的独立拟合。
- 复读三份简表、三份详细表和三份加速度表，列名、行数、文件 SHA-256 均一致。详细表保留绝对及事件相对时间字段、表观与修正速度、质量和来源；加速度表同时保留原始与拟合列。三份 metadata 的所有字段除 `exported_at_utc` 一致，包括输入单位、时间零点、STFT、质量配置、修正和加速度来源。
- 中文和英文额外缩放各独立运行一次，同基线均通过零容差比较。证据见 `artifacts/research_TASK19/figures/{baseline,production,production_en_scaled}/results.json`，两组新版各有 `parity.json`。复核工具为 `scripts/dev/research_task19_acceptance.py`。

表中质量计数用于选择和描述测试记录。应用输出可重现，但工作速度及其导数的有限点数不是物理测量有效性的证明。

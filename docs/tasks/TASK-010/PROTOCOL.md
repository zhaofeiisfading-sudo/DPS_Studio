# TASK-010 注册实验协议

2026-11-05，在运行主评价前固定。研究估计器不接收真值，不调整 Production。

主要问题是固定窗口时改变步长的独立效应，以及固定步长时改变窗口的独立效应。主矩阵为 Hann 窗 512/768/1024/1536/2048，步长 128/64/32/16/8/1；FFT 长度固定 4096，频带固定 50 MHz–6 GHz，无去均值、边界扩展、末端补帧或离散回退。新增实现采用逐批 FFT 限制内存，在相同中心逐点核对原 core STFT 和峰值细化；不改 core。

主评价复用 TASK-008 的 96 条冻结波形和 50 条低速初相压力波形。这些结果并非全新独立验证集，不能利用本轮结果调参后仍称盲测。额外 24 条新种子确认波形（6 个主要族，instance=100–103）运行预先固定的 3 窗口×2 步长，作为独立确认。完整配置见 config.json。原始数据范围包括 data/raw 全部 10 个真正的原始文件，并补充 TASK-009 已归档的 3 个原始文件；共 13 文件、17 电压流。不把 result、图片或占位文件当输入。

所有 W/H 的窗口中心都是原始样本索引。主评分网格为 1024+128k≤N−1024，保障最长窗也有完整支撑；仅按相同整数索引选择，不插值、不填缺失。原生网格另行评分以观察采样密度及定位量化误差，原生网格分母不同，不能据此声称在相同观测时刻提高精度。长窗舍弃的边界时刻及完整记录覆盖另外给出。

完整矩阵的 FFT 可从各窗口 H=1 的精确结果按整数索引抽取，所有共有中心的频率必须数值一致；输出元数据明确标记计算复用，不能把复用耗时当成独立 H 耗时。真实成本另用每个参数独立执行、3 次计时（不计导入、读取、序列化），保留逐次耗时和内存数据。内存同时报告 Windows 进程工作集、tracemalloc 跟踪分配峰值、若保留完整 complex128 谱矩阵所需的精确字节数；后者不是实测峰值。不同实现的内存上限不能混用。

候选频率严格保留 NaN，另外给出启发式支持频率：谱峰/频带中位功率对比≥10 dB，独立于 W 的 256 样本 sin/cos/DC 波形支撑 R²≥0.2、设计条件数≤10⁵。256 样本验证在原始能量事件后截掉事件前部分；这只是数据支持检查，不是独立真值验证。不同于 TASK-008 的统一 512 去直流谱对比，因此新支持列不能称为原门控的严格复现。原严格候选和原 14 方法结果分别保留，做共同中心重新评分。

RMSE 仅在真值与估计均有限处计算；同时报告全运动目标点分母上的覆盖率、NaN 比例，以及 |误差|>77.5 m/s 或 NaN 的失败率，另保留 38.75/155 m/s 阈值。无光学信号的消光段仍在运动失败率分母内；纯噪声无运动 RMSE，只评价假事件与假支持。静止段不填零、不加入运动 RMSE。速度以合成指定 λ=1550 nm 和 v_app=λf/2 计算。真实记录没有速度真值及核验波长，速度只叫假设波长等效表观速度；corrected velocity 独立为 NaN。

起跳分别评价各 W 的谱峰功率阈值越过（阈值由该 W 的 H128 前10%参考帧校准并在全部 H 间固定），以及冻结的原电压能量检测。后者对 W/H 完全独立，不能把相同得分归功于高重叠。另评价双冲击第二跳在 105 ns 附近的10/50/90%速度响应、缺失和非单调标志。阈值越过不是已校准的物理起跳测量，不用输出帧间隔替代实际瞬态支撑宽度。

次要消融全部在 H32 下改变频带和局部去均值：strict、wide_raw、wide_demean，隔离低频收益来源。固定 W/H 改 NFFT=2048/4096/8192，区别 FFT 网格细化和窗口信息。预注册双尺度策略采用去均值宽频带 W512 与 W2048，在短窗固定256样本跨度内频率变化>100 MHz时向两侧扩展1024样本选择短窗，或在原能量事件±1024样本选择短窗；其余选择长窗。直接选择，不混合、不平滑、不补 NaN；记录每点来源。

推断单位是配对独立波形。汇总分别给出 pooled RMSE 和逐波形宏平均失败/覆盖，配对 bootstrap 4000次给95%区间，不对数万重叠帧作独立样本显著性检验。区间为探索性、未作多重比较校正，不依据显著性筛选参数。相邻误差相关与固定128原始样本间隔误差相关并列，体现高重叠造成的伪重复。

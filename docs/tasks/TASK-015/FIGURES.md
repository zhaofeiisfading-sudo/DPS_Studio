# Figure evidence and QA

Python/matplotlib quantitative panels, 181.6 mm wide, Arial 8 pt base font, closed axes and inward ticks, restrained Okabe–Ito colors. Each figure is supplied as 300 dpi PNG, editable-text SVG and PDF. All panels use retained numerical outputs; no generated raster illustration or selectively edited image data.

**fig01_low_frequency:** Conditional low-frequency benefit and counterexamples. Panel a is preselected held-out low_spur index 5 (40 MHz target, 2 GHz spur, 4 dB target SNR), showing accepted frequencies; absent methods are explicitly labelled. Panel b is pooled finite-point RMSE for 16 low-tone records, with equal 75% coverage. Panels c–d show the acceptance/rejection consequences of drift, sub-cycle AC attenuation and an incorrect stationary label. No error bars in this descriptive figure; per-record data and paired record-level bootstrap comparisons are supplied in data/heldout/metrics.csv and data/paired_bootstrap.csv. A supported output is not proof of physical branch identity.

**fig02_validation:** All-target missing-inclusive failure versus coverage/error, operator-boundary sensitivity and pulse-width discrimination. Panels a–b use 288 held-out records; pure-noise records have no target-RMSE denominator. Panel c is successful-detection conditional MAE, with misses separately retained in data/boundary_summary.csv; no universal timing improvement is implied. Panel d uses four records per pulse width, all at exact physical centers spaced by 3.2 ns. Clipped methods receive exact operator boundaries as extra information. A “resolved” pulse has at least one accepted high-frequency center inside; false-high centers and width error remain in data/resolution/metrics.csv. Lines connect discrete experiment settings, not interpolated velocity estimates.

**fig03_interference:** Preselected held-out index 5 for fixed/drifting clutter; conditional success and drift failure are shown together. The lower panels aggregate all 16 records per family, reporting wrong/missing branches separately and exposing the target-in-prefix failure. No missing interval is bridged or filled.

**fig04_real_observations:** The first indexed real stream is shown as a full-record STFT power spectrogram, normalized to its global maximum, with a common −60 to 0 dB display range and Greys map. The visible y range is 0–3 GHz; this is an explicit display crop, not a data deletion. All 17 streams enter the frequency-only coverage/disagreement panel. Low GLRT is a sensitivity hypothesis, not a claimed stationary annotation. Optical calibration and independent branch truth are unavailable; agreement is not accuracy.

Visual review uses the exported PNGs from the same Python backend. Fixed log-axis minor-label crowding in fig02 and overlapping real-data labels in fig04. Final checks inspect typography, units, legend separation, axes and preservation of failures. Source code: figures.py; statistics: summarize.py. No journal submission-compliance certification is implied.

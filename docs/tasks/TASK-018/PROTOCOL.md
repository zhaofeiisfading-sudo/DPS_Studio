# TASK-018 实验协议

2026-11-11。以下规则在 TASK-018 候选审计及融合运行前固定；已知 TASK-017 结果，不是独立验证集。

- 输入仅 `data/raw` 当前 CSV/DAT；核对文件 SHA-256、样本数、通道列、采样率、原始时间、冻结分段和旧起跳中心。分母为原始索引 `q % 128 == 0` 且 `1024 ≤ q ≤ N−1024` 的全部中心；全时域图另保留边缘及不适用原因。4096 点低频 GLRT 仅在其完整窗内投票，缺窗不扣分。无重采样、补点或物理零速。Hz 和 GHz；不转换速度。
- B0：TASK-017 正式 Balanced STFT 原门控，1024/H64、Hann、NFFT4096、无去趋势。B1：TASK-017 512/H128 去均值控制，Hann/NFFT4096，保留策略原门控。B2：B1 同参数、2048 点窗；用于平台公平对照。主比较候选带 50 MHz–6 GHz，低频 GLRT 适用子带 50–250 MHz。固定中心独立于阶段。Dechirp、VarPro、Clutter VarPro、Matrix Pencil 保留原生 5 MHz–8 GHz 搜索与自动事件触发；原生胜出点出带单列，不裁边或假造带内替补。扩到 8 GHz 的诊断仅看 20201214m，重算 B0/B1/B2 并单独报告。
- 主算法分为 STFT（B0/B1/B2）、Dechirp（傅里叶调频集中度）、VarPro（含共享求解器的 Clutter VarPro）、低频 GLRT（多项式和局部干扰投影后的实正弦拟合）、子空间（LS-ESPRIT；保留原生第二极点，无原门控）。Dechirp 与 VarPro 共享 chirp-FFT 种子，且多个方法共用原始电压和自动事件规则；家族分类不表示统计独立。无事件/事件前/无完整窗不投票，运行却无合法候选记录为缺票，不冒充否定证据。低频 GLRT 不进入高频分母。
- C = 合法候选；G = 原方法门控通过（第二极点无门控）；S = TASK-017 原始 256 点窗诊断，谱对比 ≥10 dB、较背景 ≥6 dB、窗内 ≥1 周期、实 tone 或该候选原生 chirp 拟合 R²≥0.20。证据用未经 Clutter 扣除的电压；复用原规则的 50 MHz–8 GHz 噪声参考带，候选评价带仍为 50 MHz–6 GHz。背景取从原始起点开始、前最多 4096 样本的完整窗，以 TASK-017 冻结起跳下界减 2 ns 封顶（避免 20201210m 前缀混入起跳）。这条历史背景标定对所有算法共享，S2 不用阶段选算法、裁窗、分段调权或识别起跳；不得称其完全无需历史背景标定。另对全量运行无人工标定的固定记录首 5%、至多 2048 样本前缀敏感性对照（仍可能有背景污染）。
- 先审计旧 28 配置的汇总与本轮共同中心的候选集合，再融合。按每中心升频排序，从最小频率起划组，每簇最大跨度 ≤100 MHz；50/200 MHz 分别用于过窄/过宽敏感性。不在时间上连边。基准匹配另用与 B0/B1/B2 各自的直接 100 MHz 距离，单独报告中心增损和频率替换。谱诊断的邻域宽度与聚类容差不同。
- S0：每估计器总预算一票，均分到其出现的不同簇。S1：同样规则按家族计票，一个家族总预算一票，均分到其出现的不同簇；重复配置不增加家族权重。各簇按实际适用估计器/家族数归一化。S2：沿用 S1 的簇预算，只计有 S 成员的家族份额；保留所有竞争簇和原分数。S0/S1 选最高分 C，S2 选最高分 S 或空缺；同分先取贡献者多者，再以 B1、B2、B0、其余固定顺序优先保留原候选。S0/S1 代表用簇内成员，S2 用 S 成员；不生成平均频率。S2 标注单家族、跨家族和竞争 S 簇。报告 C、代表 G、代表 S、S2 已发布频率及所有候选。
- S3 单独对照：仅在冻结起跳段的原评价中心将 Dechirp/VarPro 自动事件替换为冻结起跳边界，同样做 ±2/±5 ns；同一个 S2 评分和不动的评价分母。其余时段与 S2 相同。全家族逐一留出；另合并 Dechirp/VarPro 票作为共享种子压力测试。不根据结果调权。
- 预先定义警示：相邻完整评价中心差 >250 MHz（不跨空缺）、同中心多簇、S1≥0.6 且 ≥3 家族但无 S、噪声/静止阶段的高共识、弱信号阶段的高共识、较前背景 <6 dB、带下限邻域（50–100 MHz）、同帧竞争簇近 2:1 或 3:1（100 MHz 容差）、电压连续触及全记录极值（削顶线索，非 ADC 鉴定）。这些都是回查线索，不是标注真值。分阶段、分通道、分文件列计数；双通道同文件不作为独立重复。事件仅按冻结段标签统计，无阶段标 N/A。无 RMSE、概率、因果检测延迟或精度声明。

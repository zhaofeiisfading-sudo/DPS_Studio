# TASK-018｜异构频率估计器共识堆栈

2026-11-11 · **MIXED** · Research-only

**可用于找候选和标冲突，尚不足以替代去均值短窗 STFT。** 全量 10 文件、14 路、9,475 个共同中心，50 MHz–6 GHz。S2 的原波形支持为 **5,400/9,475（56.99%）**：相对 Balanced **+543 / −0（+5.73 个百分点）**，相对去均值 512 点 STFT **+49 / −0（+0.52 个百分点）**。S2 包含基准候选且只选有支持的峰，零中心损失由规则保证；它仍替换了 13 个 B1 受支持频率（相差 >100 MHz）。与三种 STFT 的支持并集比，异构模型实际新增 40 个中心。

- **起跳：** Balanced 55/69，去均值短窗 63/69，S2 65/69。`ch3` 由 3/4 到 4/4，首个支持中心提前 3.2 ns，来自 3.414 GHz Dechirp；`20201210m` 由 Balanced 0/3 到 2/3，两点均来自 B1。人工起跳先验才让后者达到 3/3。`20201214m` 的另一新增点来自长窗约 184 MHz 瞬态，不能算带外约 6.3 GHz 平台的恢复。
- **全记录：** 相对 B1 的 49 个新增中，未知 24、噪声 10、静止 10、起跳 2、下降 2、弱信号 1；平台、加速和回升无增量。`20260607` 同一文件的双通道共贡献 20 个，主要在未知段。共同支持的 5,186 对相邻中心上，>250 MHz 跳变由 37 到 32；13 次支路替换须回查原始谱。
- **共识：** 27,775 个候选簇中 8,064 个有跨家族候选；相对 B1/B2 频率都不匹配的 15,411 个簇仅 162 个有波形支持。VarPro/Clutter VarPro 在 5,909 个共同合法中心上 100% 同簇容差内；Dechirp/VarPro 为 97.09%。单做家族归一化反而丢掉 130 个净支持点。波形约束恢复了这些点，但仍保留有强原谱的可疑支路。
- **失锁与代价：** 5,567 个高共识簇中 486 个未通过 S，1,805 个在噪声或静止段。当前每路生成估计器候选及合并需约 6–35 秒，另有原波形诊断开销；B1 约 0.13–0.78 秒。适合离线分析。没有独立支路标识或速度真值，不能推断测速精度。

下一步值得做的是用新的独立实测记录验证少量由质量触发的 Dechirp 候选，并加上可核验的物理支路参照。现有结果支持保留 B1 作为对照，不支持将八个估计器全量堆栈作为测速默认。

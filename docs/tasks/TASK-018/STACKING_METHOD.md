# S0–S3 共识方法

同一原始整数采样中心内，将合法候选按升频排列。簇的最高点与最低点相距不超过 100 MHz；候选不能通过链式匹配把跨度扩到更宽。每个簇保留所有成员。对单位 (u)，令 (m_u) 为该中心上该单位出现的不同簇数，则对每个它参与的簇贡献 (1/m_u)。S0 的单位为具体估计器，S1 的单位为模型家族。相同簇的同一家族重复候选不会增加分数；有多簇时预算在簇间均分。矩阵铅笔第二极点占同一估计器预算，并保留 `NOT_DEFINED` 原门控状态。

分数是本簇贡献之和除以在簇低端适用的单位数，取值 [0,1]。低频 GLRT 在 250 MHz 以上不进分母；若簇跨过子带边界，其低端候选可贡献。原生无事件、事件前或没有可用窗的估计器不进分母。已经运行但没给出合法点的单位可以进适用分母，只有零贡献，没有负票。单家族可取得高归一化分，故同时报告单位数与高共识的家族数门槛。分数没有校准成概率。

S2 保持 S1 的每家族预算和分母，只加有 S 成员的家族份额。S 的四项阈值见[协议](PROTOCOL.md)：原始电压局部线性基线后的谱峰对比、较前背景谱增益、窗内周期数及原电压实正弦/原生 chirp 残差。原生斜率参与验证，不从其它家族借用；非调频候选仍作零斜率比较。此诊断与模型使用同一电压，存在相关性；前背景沿用冻结起跳下界，仅作共同背景标定。固定首 5%、最多 2,048 点的对照不使用人工界限。

S0/S1 从最高分簇取原候选；S2 仅在支持簇内取原候选。候选得分、票数及固定优先顺序确定代表，平票优先保留 B1，其次 B2/B0，再按固定估计器顺序；同一簇保留一级候选优先于第二极点。没有平均频率、路径平滑或缺失补点。S2 保留未通过证据的候选簇及 S0/S1 票数，发布列在无 S 时保留 NaN；S2 的 C 与最终 `selected` 不等价。G 始终取所选来源的原门控，S2 自身没有另造一个 G。

S3 只在冻结起跳段的评价中心，用人工边界替换 Dechirp/VarPro 的自动事件起点，其它估计器不变。±2/±5 ns 改变先验输入，评价中心与背景保持不动。该对照分开导出 `prior_candidates`，其余阶段与 S2 相同。

每路 `__candidates.csv.gz` 含所有中心、原生 C/G/S、适用性、源方法、主/次候选、簇号、票数和是否被选；`__peaks.csv.gz` 含所有簇及三种模型分别选择的代表，`__curves.csv.gz` 含每模型的候选与发布轨迹、质量标签和 `source_row`。同一文件的 `source_row` 可回查精确候选；S3 的人工候选引用 `__prior_candidates.csv.gz`。图 B 的 ±50 MHz 三角带仅用于显示，横向不做插值；不参与打分或出频。

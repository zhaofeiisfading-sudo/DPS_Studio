# PDV Studio 0.2.0

## 主要更新

- **浅色工作台与矢量图标**。统一流程导航条、参数检视卡片和固定底部主操作区的布局，统一菜单、下拉框、表格和按钮的悬停、选中、聚焦及禁用配色。
- **导入与上手**。欢迎页支持拖拽导入，数据概览徽章显示采样点数和采样率。导入对话框采用双栏布局，集中设置列与单位映射，并以表格预览各列数据。
- **科学图表工作区**。图表顶部采用单行自适应控制栏，十字准星的实时坐标在控制栏内显示。算法设置可折叠，修正比较页以时间和修正速度标注坐标轴。
- **交互与性能**。参数输入在编辑完成后触发更新，减少连续键入造成的重复计算。Dechirp 拟合缓存与观测角、LiF 窗口修正解耦，可在调整这些修正参数时复用拟合结果。
- **软件更新与意见反馈**。`帮助` 菜单新增 `检查更新…` 与 `意见反馈…`：支持异步检查 GitHub `main` 正式 Release、本地缓存流式下载、强制 SHA-256 校验与原位覆盖升级，以及可关闭的启动静默检查；支持生成预填 GitHub Issue 或离线复制 Markdown 反馈（环境诊断信息默认不勾选）。
- **稳定性与导出**。加强人工频率走廊 ROI 和图表窗口的生命周期管理。导出完成后显示已写入的文件，并提供打开输出目录的快捷入口。

## 兼容性与分发

- 核心物理算法、窗函数预设、质量判据、单位换算以及 CSV 和 metadata 导出格式均与 v0.1.7 完全一致。
- 提供普通用户权限 Windows x64 安装程序（`PDV-Studio-Setup-x64.exe`），默认随程序安装无界面 CLI（`pdv.exe`）及 Agent 技能说明，全部设置、材料库与更新下载缓存集中保存在 `<安装目录>\userdata\`，原位覆盖升级自动保留用户数据。

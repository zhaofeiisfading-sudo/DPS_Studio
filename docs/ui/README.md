# PDV Studio UI 文档

本目录保存 PDV Studio 的界面设计文档。这里不放正式运行代码，也不放科学算法。

正式 GUI 代码位于：

```text
src/dps_studio/gui/
```

科学计算与数据模型位于：

```text
src/dps_studio/core/
```

依赖方向必须保持：

```text
gui -> core
```

禁止：

```text
core -> gui
```

## 当前 UI 长期流程

```text
数据导入
-> 分析范围
-> STFT 时频分析
-> 频谱脊线
-> 表观速度
-> 窗口修正
-> 质量复核
-> 导出
```

算法可以继续优化，但主操作流程原则上保持稳定。

## 科学和数据规则

- 原始数据只读，不覆盖源文件。
- 内部计算统一使用 SI 单位。
- 不静默猜测单位、丢弃额外列、插值、平滑或重采样。
- 两个 PDV 电压通道分别分析，不直接平均。
- 无可信信号时正式结果保持 `NaN`，同时保存质量标记。
- 表观速度、修正速度和仅用于绘图的显示速度必须区分。
- GUI 不重新实现 STFT、脊线、速度公式或质量判据。
- GUI 不得导入 `scripts`、`tests`、`notebooks` 或 `outputs` 作为运行依赖。
